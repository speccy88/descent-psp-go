# Architecture and limits

Baseline: complete D1X-Rebirth 0.58.1 C engine, preserved desktop target. New PSP files are under platform/psp. No engine fly-through substitute, Vita API, emulation layer, desktop GL backend or kernel plugin is shipped.

Rendering: engine's software rasterizer and portal/clipping/texture merge remain. Indexed 320x200 SDL software canvas is presented by native GU T8+CLUT sprites. Index 255 remains opaque in final presentation. GE uses two 512x272 RGBA framebuffers (1,114,112 bytes of EDRAM), no depth buffer, 131072-byte aligned main-RAM texture, 1024-byte CLUT, and a bounded 16KiB list. There is one display owner. GE synchronization precedes CPU buffer reuse; dirty texture and palette ranges are written back. No hardware 3D backend is claimed. No physical profiling yet justifies replacing the rasterizer.

Timing: monotonic PSP system microseconds, converted to the engine fixed-point timeline. Descent still calculates elapsed simulation time. PSP avoids the desktop FPS sleep loop; presentation is the sole scheduler (60 or explicit 30 FPS fallback). Pause/resume resets the monotonic delta and remains paused. No global frameskip or float conversion of fixed-point physics was added. `-fwrapv` preserves intentional signed wrapping; fixed accumulator and integer-to-fixed conversions use defined unsigned/wide operations. Focused ASan/UBSan tests cover fixed helper edge cases, not the whole engine. Legacy engine arithmetic and parser audit remains incomplete.

Input: direct action-state computation for six motion axes and firing; menu/OSK integration is separate. Input probe records the last 12 control values for reproducible emulator checks. Modifier transitions, firing suppression and neutral release were verified against those values. Configurable buttons, independent inversion, deadzone/sensitivity, aspect and presentation cap are saved in a versioned PSP config. Physical ergonomics remain unverified.

Audio: official PSP SDL 1.2 output worker plus a direct U8 effect mixer through the SDL_mixer post-mix callback, 44100Hz signed-16 stereo/1024-frame blocks. Effects borrow resident samples and use 64 slots plus a 256-frame S32 summing buffer (5,888 bytes on PSP), with no playback allocation or conversion cache. Channel controls are synchronized with SDL audio; sample owners stop slots before freeing buffers. Music is synthesized on the host using pinned TinySoundFont and a 6MB TimGM bank. PSP streams PCM through a 32768-frame SPSC ring (128KiB); producer file I/O is outside the audio callback. Atomic publication protects buffer reuse. Playback uses HMP loop ranges where supplied (game2); otherwise whole-track repeats. No whole-track PCM allocation. Audio counters measure hook blocks and music starvation, not a complete hardware-output underrun diagnostic. Tail handling and exact timbre are not claimed identical to original sound cards.

Storage: launch-relative paths (ef0:/ms0:, emulator umd0 mapping observed), PhysFS search roots for data/music and write root userdata. Recoverable game writes go through .pending with prior .bak retained; errors keep previous state where rename succeeds. This is not a FAT power-loss transaction guarantee. Unknown or foreign save compatibility is unverified. PC shareware in-level save/load is deliberately blocked per the original included shareware readme; pilot progression remains available.

Lifecycle: one user-mode startup owner, callback thread signals exit/power state, normal thread handles pausing/restoration and checked 333/333/166 clocks. PSPSDK/newlib pin supplies a weak exit that bypasses atexit; the PSP layer overrides exit to call the linked newlib exit handlers before _exit. No firmware, plugin or kernel changes.

Telemetry: up to 8192 frame samples retained in memory and written on clean exit. Interval, CPU work and GE wait are separate; overlapping stages are not summed. Initial menus/loading are included, so whole-session percentiles are not a gameplay benchmark. Heap reservation is 12MiB in standard-memory mode. The rc.3 hardware log recorded about 1.69MB free heap at gameplay entry before its unbounded sound cache exhausted memory; rc.4 removes that cache. Checkpoints report instantaneous free heap/kernel memory and remaining stack, not lifetime high-water marks. Physical performance is not certified.

Networking transports disabled (no USE_UDP). Complete single-player engine subsystems are retained, but later levels, reactor escape, secret levels with retail data, physical suspend/resume and prolonged audio have not been acceptance-tested. No 60 FPS certification is made.
